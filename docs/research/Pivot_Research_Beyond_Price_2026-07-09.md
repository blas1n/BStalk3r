# BStalk3r 방향 확장 리서치 — 가격-기술적 너머 (2026-07-09)

## 배경: 지금까지 반증된 것 (좁은 슬라이스였음)
- **저플롯 급등주 intraday**: 롱 4-shape(chase/pullback/orb/gap) 전부 gross-negative(신호 없음), 숏은 엣지 있으나 borrow 불가(실행 X).
- **유동 daily cross-sectional**: momentum/reversal 등가중 decile, 2년 검정 — 6mo 모멘텀은 신기루(2년선 reversal로 부호뒤집힘=불안정), holdout 전부 음수. 10bps 비용후 0. 잘 알려져 차익거래로 소멸.
- ⚠️ **"기술적 전멸"은 과잉 일반화**였음. 우리가 테스트한 건 (a)intraday 추격/눌림 (b)cross-sectional decile 랭킹 — **두 슬라이스뿐**. **시계열 평균회귀(레짐필터), 캘린더/구조적 효과, 이벤트, 센티먼트는 미검증.**

## 메타 원리 (문헌 수렴)
살아남는 엣지 = **순수 차익거래가 아니라 구조적/행동적 드라이버**가 있는 것:
- **기관 리밸런싱 역학**(turn-of-month: 월말 수조 달러 강제 리밸런싱) — 구조적, 소멸 안 함.
- **행동적 과잉반응**(단기 패닉 후 반등) — 지속되나 약세장에 약화(→레짐필터 필요).
- **느린 정보 확산**(PEAD) — 지속되나 감쇠.

## 후보 (실행가능성 × 지속성 × 데이터비용 순)

### A. 단기 평균회귀 (Connors RSI-2 계열) — 기술적, 미검증, **지금 즉시 테스트 가능** ⭐
- 로직: 유동 종목/ETF가 1-2일 패닉(RSI-2 과매도) + 200MA 위 → 롱, 반등 시 청산. 문헌: SPY/QQQ 1993-2025 승률 75-79%, 저비용 트레이더는 비용후 생존, **VIX 필터 추가 시 profit factor 2.15→2.99**.
- 왜 우리 테스트와 다른가: cross-sectional 랭킹 아니라 **시계열(종목별 자기 과매도)** + **레짐필터**. 완전히 다른 메커니즘(행동 과잉반응).
- 데이터: **우리 grouped daily close만으로 RSI-2/MA 계산 가능**(신규 소스 0). VIX는 무료.

### B. 캘린더/시즌성 (Turn-of-Month + FOMC drift) — 구조적, **지금 즉시 테스트 가능** ⭐
- 로직: 월말~월초 4일 보유(TOM), FOMC 전일 드리프트. 문헌: TOM은 "유일하게 지속적으로 유의한 캘린더 효과"(기관 리밸런싱). 복합 시즌 모델 Sharpe 0.77/9.56% ann. FOMC일이 수십년 주식수익의 ~절반.
- 데이터: **daily close + 날짜/FOMC 캘린더만**(신규 소스 0, FOMC 일정은 무료 고정).

### C. PEAD (실적 발표 후 드리프트) — 이벤트, 신규 데이터 필요
- 로직: 어닝 서프라이즈 방향으로 수일~수주 드리프트. 오래된 지속 아노말리지만 감쇠+비용민감+리테일 구성 의존.
- 데이터: **어닝 캘린더+서프라이즈 필요** — Finnhub/Alpha Vantage 무료 티어.

### D. 뉴스/센티먼트 — 신규 데이터+NLP 필요
- 로직: 뉴스 sentiment가 단기 방향 예측(특히 attention 스파이크+리테일 매수). 백테스트 알파 존재하나 인프라 큼(뉴스 API + FinBERT/LLM).
- 데이터: Finnhub/Alpha Vantage/Tiingo 무료 뉴스+sentiment API.

### E. 페어/통계적 차익 — 조건부, 복잡
- 여전히 되나 레짐·실행 민감, 단순 GGR은 죽음, cointegration+적응형만 생존. 실행(브로커) 이슈가 핵심.

## 무료/저가 데이터 소스 (리테일)
- **Finnhub**: 뉴스+sentiment, 어닝 캘린더, IPO, 애널 추정 (무료 티어)
- **Alpha Vantage**: 뉴스 sentiment API(AI), 50+ 기술지표 (무료)
- **Tiingo**: 뉴스 65k 티커, 500 req/hr 무료
- **Polygon**(보유): 일부 티어 social sentiment
- **우리 자산**: grouped daily 캐시(warm 496세션) + minute 캐시 + xsectional/long-search 엔진

## 권고
1. **먼저 A+B(신규 데이터 0, 즉시 테스트)** — 우리가 안 해본 기술적 계열이고 구조적/행동적 드라이버라 prior 유리. 우리 daily 캐시로 바로 백테스트(train/test/holdout+현실 비용 동일 규율). 이게 "우리가 못 찾은 기술적 방법"의 최유력.
2. **A/B가 죽으면 C(PEAD)** — Finnhub 무료 어닝 데이터 통합 후 이벤트 기반.
3. **그다음 D(센티먼트)** — 인프라 크지만 가장 비-차익거래.
4. 규율 유지: 다중검정 인지, holdout 신성, 현실적 비용(유동=수bps, 회전율 반영).
